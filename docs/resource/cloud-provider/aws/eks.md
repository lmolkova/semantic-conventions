# AWS EKS

**Status**: [Development][DocumentStatus]

An AWS Elastic Kubernetes Service (EKS) cluster is reported as a
[cloud resource](/docs/resource/cloud.md), with its cluster ARN in
[`cloud.resource_id`](/docs/registry/attributes/cloud.md#cloud-resource-id).

Use the [`k8s.cluster`](/docs/registry/entities/k8s.md#k8s-cluster) entity
for its Kubernetes cluster identity.
